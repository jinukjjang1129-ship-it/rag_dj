## 역할과 기여

사용자는 사내 강의를 직접 진행한 개발자이며, 이력서에 RAG/GraphRAG 구현, 크롤링, ML 모델링, 교육 자료 준비와8회 교육을 명시했다. 교육용 파일의 TODO를 수강생이 덜 구현한 코드라고 해석하지 않는다. 강의·제품 프로토타입·이번 자동 검증/리팩터링 변경을 구분하고 팀원별 파일 작성 기여를 추정하지 않는다.

## 이력서에 쓸 수 있는 구체적 내용

- 트윗·분봉 결합에서 가격 시각 가정과 DST 파싱, 행 수와 경과시간 수익률, 이벤트 중복, 비용 민감도가 결과를 바꾸는지 검증했다.
- RAG의 검색 hit, 목록 포함률, 답변 정확도를 분리하고 목록은 정형 조회로 처리했다. 기존 로컬 버전에 이미 있던 분산 검색은 보존했다.
- OCV4와 정답의 관계를 점검하고 OCV1~3 사전 예측을 생산일로 분리해 평가했다. 검증 AP로 모델을 선택하고 임곗값의 FP/FN trade-off를 기록했다.
- 문서 본문 참조와 조항 경계, PDF 실제 페이지를 보존하고 원문·키·벡터 저장소를 추가 게시하지 않았다.

수치에는 자료와 평가 범위를 함께 쓴다. 예: ‘제공 강의 샘플의 생산일 평가에서 검증 선택 RF의 Precision .696/Recall .500/AP .623’. 이 수치를 원래 제조 고객사의 양산 성과로 바꾸지 않는다. 긍정 결과뿐 아니라 재현되지 않은 주장과 남은 검증도 면접에서 설명한다.

## 접근 가능 자료와 남은 입력

ZIP6개, 이력서PDF, 원본 트윗/분봉, 가공 topic0/백테스트 입력, RAG 원문/인덱스, OCV 강의 샘플 Excel에 접근했다. 초기 조사에서 xlsx/parquet를 놓친 오류를 정정했다. 원래 제조 OCV 데이터와 당시 모델 학습 코드/분할, 기존 LDA 모델/환경 lock, 누락된 Trump 회귀 CSV와 중간 Excel, 데이터 재배포 권한과 원래5문항 측정 기록은 추가 확인 대상이다.
