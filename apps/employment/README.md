# 취업규칙 PDF 검색 실험

제공 PDF에서 조항과 실제 페이지를 보존해 검색하고, 생성 모델 장애 시에는 추출한 근거를 별도로 표시합니다. 독립적인 새 저장소를 늘리지 않고 기업·대학 RAG와 함께 검토합니다.

원문은 게시하지 않았습니다. Python3.12에서 `pip install -e .` 후 저장소 루트에서 실행합니다.

```bash
streamlit run apps/employment/app.py
```

PDF를 업로드하고 ‘검색 자료 준비’를 누르면 로컬 작업 경로에 자료와 인덱스가 생성됩니다. 동일 파일은 중복 적재하지 않습니다. 기본 저장 위치는 Git에서 제외된 `results/private/employment/`이며 `EMPLOYMENT_PRIVATE_DIR`로 변경할 수 있습니다. API 모드와 독립적으로 로컬 임베딩·localhost Ollama를 사용합니다.

실제38쪽 PDF의96개 청크, 반복 적재, 페이지 근거, 브라우저 검색을 확인했습니다. 같은10문항의 헤더 근거 반환은 기존1/10→수정8/10이나 자유 생성 답변 정확도가 아닙니다. 검색 실패 및 소규모 실제 생성 평가는 [상세 보고서](../../docs/document-validation.md)에 기록했습니다. 본문이나 답변 캡처를 공개하기 전에 원문 재배포 권한을 확인해야 합니다.
